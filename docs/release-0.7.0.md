# Wisp 0.7.0 — bounded Go companion tools

The server now owns its small tool workflow in Go: validate approved game context, retrieve versioned world evidence, propose observed quest choices, validate a navigation proposal, then make one bounded model request. There is no large agent framework or model-generated script execution. AI questions accept UTF-8 and request replies in the question's language; language quality depends on the model and available evidence.

The **separate OCR lab**, not this desktop ZIP, adds an optional per-question snapshot (level, area and up to four quests within the transport budget), Unicode hex transport and a click-only “Show the way” action. The game must supply a current native quest waypoint. Unsupported maps/clients, stale snapshots and character changes prevent navigation. This is not an optimal quest router or complete quest log. The finite 96-slot return experiment remains limited; reusable return transport is still separate research.

The desktop continues to provide local journeys, character switching, dated Armory context and browser chat. Mac candidates now contain Wisp.app; this does not mean signed or notarized. No OCR capture helper or experimental lab is included. Windows builds are unsigned; Mac Developer ID/notarization is pending certificate setup. Do not disable OS protections to install. No antivirus acceptance guarantee is made.

Server updates do not require downloading a new desktop. Existing personal data stays in the normal local data directory; close the old companion before replacing it. AI access requires an invite code. World knowledge is incomplete and retains source/version/uncertainty labels.
